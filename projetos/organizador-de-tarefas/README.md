# Organizador de tarefas

Projeto demonstrativo em HTML, CSS e JavaScript, sem dependências externas.

## Recursos

- Adicionar e remover tarefas
- Marcar tarefas como concluídas
- Filtrar itens pendentes, concluídos ou todos
- Salvar os dados no armazenamento local do navegador
- Layout adaptável para telas menores

## Como executar

Abra [index.html](./index.html) em um navegador moderno. Os dados ficam no navegador utilizado e não são enviados a um servidor.

## Limites

Este é um protótipo de portfólio. As tarefas são armazenadas apenas localmente e não sincronizam entre dispositivos.
