# Análise de falhas em equipamentos industriais

**Projeto acadêmico — Data Science e Big Data**

O trabalho investiga como dados operacionais de máquinas podem ajudar a identificar condições associadas a falhas e apoiar decisões de manutenção na S&M Industry Tech, empresa fictícia descrita no enunciado.

## Dados considerados

O escopo do projeto menciona registros de sensores e operação, incluindo temperatura, vibração, pressão, corrente elétrica, horas de funcionamento e ocorrência de falha.

## Etapas previstas no trabalho

1. Exploração dos dados e estatísticas descritivas com Pandas.
2. Preparação da base, tratamento de ausências, duplicidades e valores atípicos.
3. Análise de relações entre variáveis operacionais e falhas.
4. Comparação de modelos supervisionados, como Árvore de Decisão, Random Forest e Regressão Logística, usando métricas de classificação.
5. Agrupamento de perfis operacionais com K-Means.
6. Processamento de uma versão ampliada dos dados com PySpark.
7. Interpretação das limitações e elaboração de recomendações para manutenção.

## Tecnologias e métodos

**Python · Pandas · Scikit-learn · PySpark · análise exploratória · classificação · agrupamento**
