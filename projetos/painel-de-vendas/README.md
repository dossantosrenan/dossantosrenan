# Painel de vendas

Protótipo demonstrativo de indicadores em HTML, CSS e JavaScript, sem dependências externas.

## Recursos

- Alternar o período entre três e seis meses
- Atualizar total de vendas, pedidos e ticket médio
- Comparar os valores mensais em um gráfico responsivo
- Exibir moeda no padrão brasileiro (BRL)

## Como executar

Abra [index.html](./index.html) em um navegador moderno.

## Sobre os dados

Todos os valores exibidos são fictícios e foram criados apenas para demonstrar a interface. O projeto não representa dados de uma empresa ou resultados comerciais reais.
